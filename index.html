About

Building reliable software for over a decade

I'm a Senior Software Engineer and Principal Software Consultant with 10+ years of professional experience designing and delivering enterprise-grade software — from core banking and hospital ERP systems early in my career to AI-powered workflow automation, retrieval-augmented generation (RAG) platforms, and multi-vendor network security orchestration today.

My work spans the full stack: software architecture and system design, backend engineering in .NET, Python, and Node.js, frontend development with React and Angular, RESTful and OData API design, and cloud infrastructure on Microsoft Azure. In recent years I've focused heavily on applied AI — building RAG pipelines, multi-agent orchestration, and LLM-integrated platforms that are grounded, auditable, and enterprise-ready.
